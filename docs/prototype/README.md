# MarkShot 原型演进

这里保留 MarkShot 从 Markdown 阅读器到统一阅读与分享工作台的界面原型。文件均为可直接打开的独立 HTML，并按照产生和演进顺序编号。

1. `01-markdown-reader-modes.html`
   - 第一阶段：比较四种 Markdown 阅读器风格与布局，并补充即时分享入口。
2. `02-classic-tabs-studio.html`
   - 第二阶段：将经典阅读器与双栏工作台结合，探索多文档和标签页结构。
3. `03-unified-reading-share.html`
   - 当前基线：统一阅读、即时粘贴、风格预览和图片分享，改用可收起的左侧即时/文件区域。
4. `04-brand-wordmark-comparison.html`
   - 品牌探索：集中比较四款 MarkShot 横向文字标识在应用标题栏与分享页脚中的效果。
5. `05-brand-layout-compact.html`
   - 品牌定稿：采用原始方案 B，保持现有结构，仅替换左上角品牌与图片页脚。
6. `06-brand-layout-product.html`
   - 品牌布局二：增加轻量产品定位和更完整的分享来源签名。
7. `07-brand-layout-share-first.html`
   - 品牌布局三：用深色标题栏品牌区和居中页脚强化分享传播辨识度。
产品功能与工作区布局仍以 `03-unified-reading-share.html` 为主要参考；`05` 记录已选品牌方案，其他品牌文件作为方案归档保留。
