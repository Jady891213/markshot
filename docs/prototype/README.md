# MarkShot 原型演进

这里保留 MarkShot 从 Markdown 阅读器到统一阅读与分享工作台的界面原型。文件均为可直接打开的独立 HTML，并按照产生和演进顺序编号。

1. `01-markdown-reader-modes.html`
   - 第一阶段：比较四种 Markdown 阅读器风格与布局，并补充即时分享入口。
2. `02-classic-tabs-studio.html`
   - 第二阶段：将经典阅读器与双栏工作台结合，探索多文档和标签页结构。
3. `03-unified-reading-share.html`
   - 当前基线：统一阅读、即时粘贴、风格预览和图片分享，改用可收起的左侧即时/文件区域。

后续产品界面调整以 `03-unified-reading-share.html` 为主要参考；前两个文件作为历史方案保留。
