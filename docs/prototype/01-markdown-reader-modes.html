让 Markdown 重新变得好读、好看、好分享

MarkShot 不只是一款把 Markdown 变成长图的工具。它首先应该提供完整、自然的阅读体验， 然后把这份阅读体验延伸为易于分享的图片。

阅读和分享不是两套渲染结果，而是同一份 Markdown 内容的两种出口。

一、本地阅读

双击任意 .md 文件即可打开。文档保持可选中、可搜索，并按照系统主题自动显示。

  • 记录最近打开的文档
  • 监听源文件变化并自动刷新
  • 保留标题、表格、代码和脚注样式

二、分享输出

阅读完成后，点击“分享”进入现有的长图配置界面。移动端和 PC 尺寸不影响当前阅读布局。 

const document = await openMarkdown(path);
