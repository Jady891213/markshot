让 Markdown 重新变得好读、好看、好分享

MarkShot 不只是一款把 Markdown 变成长图的工具。它首先应该提供完整、自然的阅读体验， 然后把这份阅读体验延伸为易于分享的图片。

最近打开负责找回历史，多标签页负责维持当前工作集。

一、两种导航各司其职

左侧保留最近文件，顶部标签页展示当前正在处理的文档。点击最近文件时，如果它还没有标签页， 就在顶部新建一个；如果已经打开，则直接切换到对应标签。

  • 最近文件：回到之前看过的内容
  • 标签页：在当前几份文档间快速切换
  • 右侧目录：在当前文档内部跳转

二、阅读与编辑共用一个工作台

默认使用阅读模式，需要查看 Markdown 原文时切换到“双栏”，需要专注编辑时切换到“源码”。 

Recent files → Open tab → Reader / Split / Source
